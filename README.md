# Міні-проєкт 2 (модуль 2): світлофор за ПДР

Міні-проєкт курсу Embedded Basic, базовий рівень, без 7-сегментних індикаторів.
Плата ESP32-S3-WROOM-1-N16R8, PlatformIO, Arduino.

Відео: [demo.mp4](demo.mp4)

## Схема

Розводка на макетці: [map.svg](map.svg).

```
GPIO18 -> 220 Ом -> червоний LED -> GND
GPIO17 -> 220 Ом -> зелений LED -> GND
GPIO16 -> 220 Ом -> жовтий LED -> GND
GPIO4 -> кнопка з RC-фільтром (як у домашці 2.4)
```

## Що робить

Цикл станів:

| Стан | Час |
|---|---|
| червоний | 10 с |
| червоний + жовтий | 2 с |
| зелений | 10 с |
| зелений миготливий | 3 с, 1 Гц |
| жовтий | 3 с |

Кнопка вмикає жовтий миготливий. Повторне натискання повертає на червоний.

Код поділений на три частини: ініціалізація, логіка станів, відображення. У GPIO пише лише `render()`. Без `delay`.

## Перевірка

Часи станів з логу: 10 · 2 · 10 · 3 · 3 с. Кольори звірив очима на повному циклі.
Кількість натискань кнопки проти кількості переходів окремо не рахував.

## Запуск

```
pio run -t upload -t monitor
```
